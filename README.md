# Dynamique des groupes

Présentation interactive en français pour le cours de communication professionnelle.

## Ouvrir la présentation

Ouvrir index.html dans un navigateur. Conserver les fichiers script.js, style.css et le dossier assets à côté du fichier HTML.

- Flèches gauche et droite : changer de diapositive.
- F : plein écran.
- N : afficher les notes pour l'explication orale.
- S : ouvrir le sommaire.
- Les boutons des scènes permettent de faire évoluer les situations et de révéler les corrections.

## Contenu

- Introduction à la dynamique des groupes.
- Approche théorique de Kurt Lewin.
- Perceptions, images sociales et biais de jugement.
- Structuration et organisation des groupes.
- Activités en groupe et mini-quiz final.

Les illustrations et animations servent de supports pédagogiques. Le portrait, les illustrations et les animations sont locaux. Les polices en ligne sont facultatives : une police de secours est utilisée sans connexion.

Présentation : Islam Chaachaa & Ayman Yassine.

Les trois fichiers part1.mp4, part2.mp4 et part3.mp4 doivent rester à la racine, à côté de index.html. Les commandes permettent la lecture, la pause et le plein écran. La lecture s’arrête au changement de diapositive.
